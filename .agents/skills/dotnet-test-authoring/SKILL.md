# .NET Test Authoring

Read `dotnet-clients/CLAUDE.md` and `dotnet-clients/README.md` first. This vouchington-clients repository puts portable behavior in `tests/Voucha.Client.Core.Tests`; rendered MAUI behavior belongs in `tests/Voucha.Client.App.Tests`. Batch compatible changes in one no-mistakes selection plan. Source files have a 200-line cap and tests a 500-line cap; validate rendered changes against Mac Catalyst.

Filaments native-selection and host-lock guidance is authoritative at https://github.com/jonathanong/filaments/blob/main/docs/checklists/commit.md#native-selection and https://github.com/jonathanong/filaments/blob/main/docs/development/host-locks.md.
