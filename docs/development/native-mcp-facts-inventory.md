This change adds `read_feed.rss_items` as RSS item delivery identifiers only. Neither feed result is a hydrated card. Existing copy supplies “Posts”, “Post ID”, and “No posts yet” for posts. RSS rows use the Swift heading “RSS item”, the shared “RSS item ID {id}” value, “No results” for an empty delivery list, and the .NET heading “RSS feed item”. Financial value labels and a cross-client mutation statement need producer-owned localization before a truthful native renderer. Referral deliveries still need option-specific copy.
